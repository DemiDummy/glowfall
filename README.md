# Glowfall

Light the dark. Hold the light. A post-apocalyptic colony-survival RTS for the browser: relight Ember Station, a
dead nuclear reactor; build a colony around it that feeds, waters and powers itself; then hold it while the
irradiated dead, mutant brutes and Rustjaw raiders come for its Glow. The brighter it burns, the more of them come.

**Play it at https://demidummy.github.io/glowfall/** (desktop browser, mouse and keyboard).

Drag to select, right-click to move and attack, B opens the build menu, Space pauses (you can still build).
"How to play" on the title screen lists every control.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
